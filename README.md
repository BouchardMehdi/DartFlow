# DartFlow

Application mobile-first de comptage de points aux fléchettes. Cette première version fournit une démonstration Count-Up locale, une cible SVG accessible, un moteur pur et une annulation par restauration d’état.

## Démarrage

```bash
npm install
npm run dev
```

## Vérifications

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```
